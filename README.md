# 4 Spaces
A game where you have to beat the bot to claim 4 spaces in a row, column, or diagonal and win.

## Compile Instructions
(These are Windows 10 instructions; I'm not sure if they work with other OS/versions)
- Make sure MinGW is installed (if not you can try this [tutorial](https://www.geeksforgeeks.org/cpp/installing-mingw-tools-for-c-c-and-changing-environment-variable/))
- Add MinGW to the system PATH
- Download the program.c file from the source code
- Open a command prompt window
- Use the cd command to travel to the directory that has the program.c file
- Run gcc program.c -o program.exe 

## Execution Instructions
- Download the .exe file from Github releases
- Run the .exe file
